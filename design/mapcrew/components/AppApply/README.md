# AppApply

The application flow: six short steps behind a progress bar (name and email, phone, date of birth, ZIP and radius and car, availability, review), then a 6-digit SMS code.

- One topic per step, a "Continue" button in the bottom bar, and the next step named under it.
- Date of birth states the 18+ rule and that ID is checked before the first mission.
- The SMS screen has no countdown timer: "Resend code" is always available.
