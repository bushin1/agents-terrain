# Badge

Short status labels (`.mc-badge`) and the visit sync indicator (`.mc-sync`).

- **Provide:** a tone class — `--bonus`, `--success`, `--pending`, `--danger`, `--outline` or none — an icon for status tones, and one to three words.
- `--bonus` is the only promotional badge. There are no "Hot", "Limited" or countdown badges.
- `.mc-sync` sits in the visit app bar at all times during a visit: Synced, Syncing (spinning icon), Offline · saved on phone.
- Badges are 26px tall and not tappable; when a badge must act (location filter), use a chip or button.
